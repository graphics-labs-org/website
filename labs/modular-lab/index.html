La Matemática del Reloj

La aritmética modular es un sistema matemático donde los números "dan la vuelta" al alcanzar cierto valor (el módulo), como las horas de un reloj. En esta visualización, colocamos $N$ puntos alrededor de un círculo. Esta rama de las matemáticas es fundamental en criptografía, informática y teoría de números.

El Algoritmo

Para cada punto $i$ en el círculo, dibujamos una línea conectándolo con el punto resultante de multiplicar $i$ por el factor multiplicativo $M$, aplicando la operación módulo $N$. Este proceso crea envolventes de líneas que definen curvas geométricas conocidas como epicicloides.

Destino = (i × M) mod N

Cuando $M = 2$, las cuerdas forman la silueta de una Cardioide (una forma de corazón). Cuando $M = 3$, aparece una Nefroide (forma de riñón). A medida que $M$ aumenta o cambia mediante valores decimales, emergen patrones de interferencia extremadamente complejos y caóticos que de repente recuperan la simetría perfecta en valores enteros.
